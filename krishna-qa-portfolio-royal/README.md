# Krishna Kumar — QA Portfolio

Royal-themed React + Vite portfolio for a Software Tester / Quality Analyst.

Included: supplied profile photo, supplied resume download, responsive layout, dark/light theme, smooth navigation, hover effects, animated hero/profile, experience, skills, API testing, projects, education, achievements and contact section.

Run:
`npm install`
`npm run dev`

Build:
`npm run build`

Deploy easily to Vercel/Netlify. The portfolio intentionally does not invent LinkedIn/GitHub URLs or certifications because they were not present in the supplied resume.
